# H.O.P.E Hand — 손가락 마비 재활을 위한 와이어 기반 소프트 재활 로봇

**H.O.P.E Hand**(팀 희망회로, 2026 소원 H.O.P.E Project, 광운대학교)는 뇌졸중 등 신경계 질환으로 인한
상지(손가락) 마비 환자를 위한 저비용 와이어 기반 소프트 웨어러블 재활 로봇이며, 환자의 통증 피드백에
실시간으로 반응해 모터 속도를 조절하는 **선형 컨텍스추얼 밴딧(LinUCB) 강화학습 제어기**를 탑재했다.

> 이 저장소는 포트폴리오 공개를 위해 프로젝트의 제어/GUI 소프트웨어만 정리한 것이다. 글러브 하드웨어
> (가위식 구조, 벨로우즈, 배선)와 아두이노 펌웨어는 포함하지 않으며, 재활 로직을 실행하고 시리얼로
> 모터를 구동하며 임상 UI를 렌더링하는 PC측 파이썬 애플리케이션만을 다룬다.

## 문제 정의

- 뇌졸중 생존자의 대다수가 편측마비를 겪으며, 그중에서도 손가락 마비는 일상생활에 가장 큰 불편을
  주지만 기존 재활 로봇은 지나치게 고가(근전도 센서 기반 기기는 약 7,700만 원대)이거나, 힘 피드백이
  없는 공압식 글러브(SYREBO 등)처럼 기능이 단순해 병원·가정 보급에 적합하지 않다.
- 기존 기기들은 환자의 통증 내성에 맞춰 실시간으로 보조력을 조절하지 못하여, 강직이 심한 관절을 안전
  범위 이상으로 강제 구동할 경우 조직·근육 손상의 위험이 있다.

## 제안 방법

**하드웨어 개념.** 면 재질 장갑에 벨크로로 고정한 손가락별 실리콘 와이어 거치대가 손등 방향으로
텐던 와이어를 거치시키며, 손가락당 1개의 서보모터로 구동되는 텐던 구동 방식이다. 
손가락 손등 방향에는 플렉시블 센서(관절 각도 측정), 손바닥에는 FSR 압력센서(악력 측정)가
부착된다. Arduino Nano가 센서를 읽고 서보를 구동하며, 이 저장소가 다루는 PC측에서는 제어 로직과
임상 UI를 담당한다.

**제어 소프트웨어 — 3단계 구조:**

1. **캘리브레이션.** 처음 착용 시 각 손가락을 전체 가동범위까지 수동으로 움직여 기계적 최소/최대
   서보 각도(`M1_INIT_POS`/`m1_limit`, `M2_INIT_POS`/`m2_limit`)와 그에 대응하는 플렉시블 센서 값
   (`flex_max_open`/`flex_max_close`)을 측정·저장한다. 이어서 5초간 악력을 측정해 초기 모터 속도
   `initial_k`를 환자의 FSR 측정값에 비례해 설정한다.
2. **LinUCB 기반 적응형 보조.** 수천 번의 시행이 필요한 심층강화학습(DQN, PPO 등) 대신, 한 세션에
   수십 번의 제어 스텝만 발생하는 재활 환경 특성에 맞춰 **선형 컨텍스추얼 밴딧(LinUCB)** 알고리즘을
   채택했다. 매 제어 스텝마다 `[정규화된 굽힘 위치, 정규화된 악력, 베이지안 안전 점수, 바이어스]`의
   4차원 컨텍스트를 바탕으로 이산 속도 암 집합(`SPEED_ARMS = [k, k+10, k+20, k+30]`) 중 하나를
   선택한다. 에이전트는 두 가지 피드백 경로로 온라인 업데이트된다.
   - **키보드/버튼 통증 신호** — `0`=통증 없음(사이클 완료 시 보상 +10, 안전 점수 점진적 회복),
     `1`=뻐근함(보상 −10, 안전 점수 ×0.8), `2`=강한 통증(보상 −100, 즉시 초기 위치로 롤백, 안전
     점수 ×0.4), 능동 구동 중 `3`/스페이스바는 긴급 정지.
   - **동적 가동범위(ROM) 확장** — 통증 신호 없이 굽힘/신전 사이클이 성공적으로 완료될 때마다 다음
     사이클의 목표 ROM을 2%씩 확장(물리치료의 점진적 과부하 원칙을 구현); 통증 발생 시에는 즉시
     캘리브레이션된 안전 기준값으로 목표 ROM을 되돌린다.
3. **GUI 및 세션 리포트.** PyQt5 애플리케이션(`RehabApp`)이 백그라운드 `QThread`(`RehabWorker`)에서
   제어 루프를 실행해 UI 반응성을 유지하며, 실시간 굽힘 진행률과 사이클/통증 누적 카운터를 표시한다.
   세션 종료 시 전체 사이클 로그를 엑셀로 저장할지 묻고, 3분할 Matplotlib 리포트(ROM 성장 곡선, 통증
   발생 비율 파이차트, 손가락 굽힘 범위 상의 통증 발생 지점 산점도)를 생성한다.

## 하드웨어

최종 시연된 프로토타입은 **검지·중지 2지** 텐던 구동 방식이며, 스트랩·와이어 조립체가
**탈부착식**이라 다섯 손가락을 전부 만들지 않고도 원하는 손가락에 바로 옮겨 장착할 수 있다.
구성품은 면 재질 장갑, 3D 프린팅한 서보 장착 브라켓과 벨크로+실리콘 와이어 거치대 방식의 텐던
구동부,
배터리·구동 회로 본체, 그리고 캘리브레이션에 쓰이는 별도의 손가락 근력(악력) 측정 스위치로
이루어진다. 학교 지급 예산은 사용하지 않았으며, 부품은 자비로 조달하고 필요한 부품은 3D 프린터로
직접 제작하였다.

재활 데이터셋과 시뮬레이터를 공개할 계획이다.

## 저장소 구조

```
hope-rehab-robot/
├── src/
│   └── rehab_app.py      # 전체 제어 + GUI 애플리케이션 (시리얼 I/O, LinUCB 에이전트,
│                          # 셋업/캘리브레이션 상태 머신, PyQt5 GUI, 세션 리포트)
├── requirements.txt
└── README.md / README.ko.md
```

## 실행 방법

```bash
pip install -r requirements.txt
python src/rehab_app.py
```

스크립트는 `DATA,<flex>,<fsr>\n` 형식의 간단한 프로토콜로 데이터를 보내고
`M<motor_num>,<angle>,<speed>\n` 명령을 받는 아두이노가 시리얼 포트에 연결되어 있다고 가정한다
(`PORT = 'COM3'`, `BAUD = 115200` — 환경에 맞게 수정 필요). 아두이노가 연결되어 있지 않아도 앱은
"미연결" 모드로 구동되며(모터 명령은 무시되고 센서 값은 기본값 유지), 하드웨어 없이 제어 흐름과
GUI를 확인하는 데 유용하다.

## 결과 

- 텐던(와이어) 구동 방식의 2지(검지·중지), 탈부착식 프로토타입을 제작해 시연했으며, 플렉시블/FSR 센싱 루프, Arduino
  Nano 제어, LinUCB 기반 보조가 엔드투엔드로 통합되었다.
- 보고서의 "Model Convergence: Uncertainty Decay" 그래프는 재활 사이클 초반부터 LinUCB 에이전트의
  행동가치 불확실성이 거의 0으로 수렴함을 보여준다. 즉, 적은 샘플만으로도 안정적인 속도 정책에
  수렴하는데, 이는 한 세션당 제어 스텝이 수십 번에 불과한 재활 환경에서 DQN/PPO 대신 LinUCB를
  선택한 설계 근거와 일치한다.
- "Patient Compliance vs. ROM Expansion" 그래프는 베이지안 안전 점수와 동적 ROM 목표가 설계
  의도대로 상호작용함을 보여준다. 통증이 보고되지 않아 안전 점수가 높게 유지되는 구간에서는 ROM이
  꾸준히 확장되고, 통증 이벤트(2번 버튼)가 발생하는 즉시 두 값 모두 캘리브레이션된 기준값으로
  동시에 복귀한다. 즉, 점진적 과부하 및 안전 롤백 로직이 기록된 세션에서 의도대로 작동했다.

## 향후 개선 계획 

1. **하드웨어** — 와이어 장력 전달 구조를 보완해 더 안정적인 움직임을 구현하고, 재활 모드를
   다양화하며, 장치를 소형화해 실제 착용 가능한 웨어러블 형태로 발전시킨다.
2. **인공지능 알고리즘** — 현재의 선형 밴딧을 넘어 환자의 복잡하고 불규칙한 통증 반응까지 정밀하게
   파악할 수 있는 모델을 도입하고, 현재 고정값인 2% 가동범위 확장 비율도 AI가 스스로 판단·조절하도록
   확장한다.
3. **센서·하드웨어 신뢰성** — 단일 플렉시블 센서를 다른 보조 센서와 결합해 각도 측정 오차를 줄이고,
   근전도(EMG) 센서를 추가해 환자가 버튼을 누르지 못하는 상황에서도 무의식적인 근육 뭉침을 감지한다.
4. **임상 데이터 기반 맞춤형 치료 강화** — 단발성 치료 기록을 넘어 여러 회차의 치료 데이터를 누적
   관리하여 다음 세션에서 환자에게 맞는 최적의 치료 강도를 더 빠르게 찾고, 실제 환자 대상 임상 시험을
   통해 AI 모델의 내부 설정값을 실제 의료 데이터에 맞게 최적화한다.
5. **소프트웨어 구조 및 안정성 개선** — 현재의 단일 스크립트를 모듈·객체 단위로 재구성해 유지보수와
   기능 추가를 쉽게 하고, 장비-PC 간 통신 두절이나 예기치 못한 오류 발생 시 모터가 즉각 정지하고
   안전 상태로 전환되는 자동 안전 정지 설계를 강화한다.
